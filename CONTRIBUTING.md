# Contributing

Thanks for your interest in contributing!

## Quick Start

1. Fork the repo
2. Create feature branch (`git checkout -b feature/amazing-feature`)
3. Commit changes (`git commit -m 'Add amazing feature'`)
4. Push (`git push origin feature/amazing-feature`)
5. Open Pull Request

## Development

- Run `cargo build` to check compilation
- Use `cargo test` before PR
- Follow existing code style (rustfmt, clippy)

## Issues

- Check existing issues before creating new
- Use labels: `bug`, `feature`, `good first issue`
- For bugs: include OS version, steps to reproduce

## Questions?

Open a discussion or contact via GitHub
